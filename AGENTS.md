# Repository instructions

Start with `AGENT_ENTRY.md` and open only the files needed for the current task.

Treat `CANDIDATE.md`, databases, resumes, application materials, recordings and transcripts as private local data. Do not print or commit their contents. Use candidate facts only when the requested task requires them.

Do not submit applications, send messages or contact employers without explicit user approval.

Use `career.py` or the `career-agent` command for state changes. Do not edit the generated Excel tracker as a database.

Before any commit, inspect `git status --short` and keep generated or personal files out of Git.
