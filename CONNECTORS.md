# Коннекторы вакансий

Все источники запускаются через единый CLI и приводятся к модели `Vacancy`.

## Команды

Поиск по включённым источникам:

```bash
python3 career.py jobs search
```

Один или несколько выбранных источников:

```bash
python3 career.py jobs search --source remotive
python3 career.py jobs search --source jobicy --source arbeitnow
```

Проверка без сохранения:

```bash
python3 career.py jobs search --source remotive --limit 20 --dry-run
```

Обновление уже сохранённых карточек:

```bash
python3 career.py jobs refresh
python3 career.py jobs refresh --source remotive
```

## Источники

| ID | Доступ | Статус по умолчанию | Интервал |
| --- | --- | --- | --- |
| `hh.ru` | публичный API | включён | без дополнительного ограничения |
| `remotive` | публичный API без ключа | включён | 6 часов |
| `jobicy` | публичный API без ключа | включён | 3 часа |
| `arbeitnow` | публичный API без ключа | включён | 1 час |

Интервалы хранятся в `config/career.json`. `--force` игнорирует интервал и предназначен для диагностики, а не регулярного запуска.

## Семантика статусов

- HH.ru позволяет запросить конкретную карточку.
- Remotive публикует список активных вакансий, поэтому отсутствие ранее сохранённой записи в полном снимке помечается как недоступность.
- Jobicy предоставляет ограниченное окно свежих публикаций. Отсутствие старой записи в выдаче не считается закрытием.
- Arbeitnow обновляет найденные записи. Отсутствие в ограниченном числе страниц не считается закрытием.

Каждый запуск записывается в таблицу `connector_runs`. Ошибка одного источника не отменяет результаты остальных.

## Атрибуция

Markdown и Excel сохраняют название площадки и исходную ссылку. Это требуется правилами Remotive и Jobicy и помогает проверять карточку на оригинальном источнике.
