# Career Agent

Career Agent превращает папку с резюме, вакансиями и историей откликов в рабочее место для кодового агента. Вы открываете репозиторий в агенте и пишете обычными словами, что нужно сделать:

> Найди свежие вакансии Junior Python и LLM, убери неподходящие и покажи пять лучших.

Или:

> Обнови сохранённые вакансии. Покажи, какие закрылись и где появились новые требования.

Агент сам находит нужные инструкции в репозитории, запускает команды, сохраняет вакансии и ведёт этапы отклика. Для обычной работы не нужно помнить устройство проекта или вручную перекладывать данные между таблицами.

## Основной сценарий

1. Клонируйте репозиторий.
2. Установите проект.
3. Создайте локальный профиль кандидата.
4. Откройте папку в кодовом агенте.
5. Пишите агенту, что хотите сделать.

Если кодовый агент работает по вашей подписке, отдельный ключ текстовой модели для Career Agent не нужен. Сам проект не обращается к LLM API для анализа текста. Коннекторы вакансий используют открытые API без авторизации.

Файлы `AGENTS.md` и `AGENT_ENTRY.md` объясняют агенту, где лежат данные, какие команды запускать и когда нужно запросить ваше подтверждение. Например, агент не должен отправлять отклик или писать работодателю без прямого разрешения.

## Установка

Понадобится Python 3.10 или новее.

```bash
git clone https://github.com/ivanVgusev/career-agent.git
cd career-agent
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

В Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
```

Создайте профиль кандидата из шаблона:

```bash
cp templates/CANDIDATE.example.md CANDIDATE.md
```

Заполните `CANDIDATE.md` проверенными фактами об опыте, проектах, образовании и ограничениях. Агент будет брать сведения для резюме и писем только из этого файла. Git его игнорирует.

Инициализируйте локальную базу:

```bash
career-agent init
```

Теперь откройте папку в агенте и начните с запроса:

> Проверь настройки поиска, найди 20 вакансий в тестовом режиме и объясни, какие фильтры стоит изменить под мой профиль.

## Что можно поручить агенту

### Поиск вакансий

> Найди удалённые стажировки и junior-позиции по Python, NLP и LLM. Сначала ничего не сохраняй, покажи результаты и причины оценки.

Career Agent ищет вакансии на HH.ru, Remotive, Jobicy и Arbeitnow. Настройки лежат в `job-search/hh_search.json`, а правила первичной оценки находятся в `career_agent/domain/scoring.py`.

### Разбор выбранной вакансии

> Разбери вакансию `hh.ru:123456789`. Сверь обязательные требования с моим профилем и честно перечисли пробелы.

Агент читает одну выбранную вакансию и `CANDIDATE.md`, проверяет формат работы, опыт, технологии и стоп-факторы. Автоматический балл помогает отсеять шум, но не заменяет разбор полного описания.

### Подготовка отклика

> Подготовь под эту вакансию резюме и сопроводительное письмо. Не отправляй их, пока я не проверю файлы.

Процесс разбит на этапы: проверка источника, анализ требований, матрица подтверждений, адаптация резюме, ATS-проверка, письмо и пользовательское подтверждение. Состояние этапов хранится в SQLite.

### Работа со статусами

> Я отправил отклик на `hh.ru:123456789`. Обнови статус и дату.

Вакансии, отклики и история изменений хранятся в `data/career.db`. Excel-трекер и Markdown-карточки создаются из базы, поэтому их не нужно поддерживать вручную.

### Разбор собеседования

> Расшифруй запись собеседования, посчитай метрики речи и подготовь разбор по рубрике.

Для локальной транскрипции установите дополнительные зависимости:

```bash
python -m pip install -e '.[speech]'
```

Career Agent может обратиться к совместимому speech-сервису, а при его недоступности использовать локальный `faster-whisper`. Адрес и модели задаются в `config/career.json`.

## Если хочется работать руками

Агент запускает тот же CLI, который доступен пользователю:

```bash
# Поиск без сохранения
career-agent jobs search --dry-run --limit 20

# Обычный поиск
career-agent jobs search

# Список сохранённых вакансий
career-agent jobs list

# Обновление карточек
career-agent jobs refresh

# Загрузка вакансии HH.ru
career-agent jobs fetch https://hh.ru/vacancy/123456789

# Изменение статуса
career-agent jobs status hh.ru 123456789 "Рассматриваю"

# Этапы подготовки отклика
career-agent jobs workflow init --source hh.ru --source-id 123456789
career-agent jobs workflow list --source hh.ru --source-id 123456789
career-agent jobs workflow set hh.ru 123456789 verify_source done

# ATS-проверка
python job-search/ats_check.py vacancy.md resume.md
```

Вместо команды `career-agent` можно запускать `python career.py`.

## Где хранятся данные

```text
data/career.db                       локальная база вакансий и откликов
job-search/tracker.xlsx              Excel-представление базы
job-search/vacancies/                карточки вакансий
job-search/resumes-adapted/          адаптированные резюме
job-search/cover-letters/            сопроводительные письма
job-search/application-kits/         материалы для отклика
interview-coach/recordings/          записи собеседований
interview-coach/transcripts/         расшифровки
interview-coach/analysis/            разборы интервью
```

Эти пути добавлены в `.gitignore`. В публичный репозиторий не должны попадать:

- `CANDIDATE.md`;
- базы и Excel-трекеры;
- резюме, письма и пакеты отклика;
- записи, транскрипты и разборы собеседований;
- `.env`, ключи, токены и частные сетевые адреса.

Перед публикацией изменений проверяйте `git status --short`. Дополнительный чек-лист находится в [SECURITY.md](SECURITY.md).

## Как всё устроено

```text
внешний источник -> адаптер -> сервис -> SQLite -> Markdown и Excel
аудиозапись -> speech-сервис или локальный Whisper -> транскрипт -> метрики и разбор
```

- `career_agent/domain/` содержит модели и правила оценки.
- `career_agent/adapters/` работает с внешними источниками.
- `career_agent/services/` выполняет пользовательские сценарии.
- `career_agent/repositories/` хранит состояние в SQLite.
- `career_agent/exporters/` создаёт Markdown и Excel.
- `AGENT_ENTRY.md` направляет кодового агента к нужной инструкции.

Подробнее: [ARCHITECTURE.md](ARCHITECTURE.md) и [CONNECTORS.md](CONNECTORS.md).
